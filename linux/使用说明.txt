桌面小猫 —— 统信 UOS / 深度 Deepin / Debian 系 Linux
（x86_64 和 ARM64 通用，装一次就好）
========================================

猫的本体和 Windows 版是同一套（cat.js）+ 同一套 3D 模型，
换的只是外壳：Windows 用 Tauri，这里用 Python + Qt。


【最简单的装法：双击安装包】

   1. 双击  桌面小猫_1.0.0_all.deb
   2. 弹出「软件包安装器」→ 点「安装」→ 输入开机密码
   3. 第一次要联网下依赖（约 50MB），等进度条走完
   4. 打开「开始菜单」搜「桌面小猫」，点开就出来了

   想让它开机自己冒出来：右键小猫（或者托盘图标）→ 勾「开机自动启动」。


【双击提示「不允许安装」/ 没反应】

   UOS 专业版开着「安全模式」时只让装官方签名的包。两个办法，任选：
     a) 控制中心 → 通用 → 安全 → 关掉「安全模式」（需要管理员密码）
     b) 打开终端（Ctrl+Alt+T），把安装包拖进终端窗口，敲：
            sudo dpkg -i 桌面小猫_1.0.0_all.deb
            sudo apt install -f


【装完点图标，弹窗说「缺少运行依赖」】

   启动器会自己尝试补装（会弹一次系统密码框）。要是还不行，终端敲这一行：
       sudo apt install python3-pyqt5.qtwebengine python3-xlib
   装完再点一次图标。


【卸载】
   终端：  sudo apt remove deskcat
   或者用「软件包管理器」搜 deskcat 删掉。
   个人配置在 ~/.config/deskcat，想彻底干净就一起删。


【不想装，先试一下】
   解压后在「源码」目录里：
       sh run.sh
   不用装任何东西（但依赖还是得有，见上面那行 apt install）。


【出问题先跑自检（比截图有用）】

       python3 /usr/share/deskcat/selfcheck.py

   （没装 deb 的话：cd 到源码目录，python3 selfcheck.py）

   它会逐项报：Python 依赖 / X11 会话 / RECORD 扩展 / 桌面合成器 /
   中文字体 / 显卡渲染方式。把这几十行输出贴出来，基本就能定位。


【它会做什么】

   · 你敲键盘：对应的爪子按到那个键上，键帽亮起，头顶弹出字符
   · 你动鼠标：一只爪子搭在小鼠标上跟着晃，眼睛盯着你的光标
   · 你点鼠标（左右键都行）：桌上那只小老鼠会被按扁、亮一下，爪子搭上去跟着按
   · 按住它的头：闭眼蹭你的手
   · 双击它：原地转一圈
   · 拖它：按住身子拖到任意位置，位置会记住
   · 没人理它：舔毛、甩尾巴、打哈欠，久了会趴下来睡着冒 z Z z


【右键菜单】

   大小（80% / 100% / 125% / 150%）
   毛色（奶牛、橘猫、狸花、三花、白猫、蓝灰）
   多久睡着（1 / 2 / 5 / 15 分钟 / 几乎不睡，默认 15 分钟）
   转一圈 / 去睡觉
   开机自动启动
   锁定位置（锁定后鼠标彻底穿透，只能从托盘或再右键解锁）
   退出小猫
   软件均是免费开源，切勿商用买卖（这行是声明，灰的，点不动）

   托盘图标里也有「转一圈 / 去睡觉 / 退出」。
   万一锁定了又找不到托盘图标：终端 killall python3，
   或者把 ~/.config/deskcat/config.json 里的 "locked" 改成 false。


【已知取舍（这版没在真机上验证过，先说清楚）】

▶ 点猫的那一下，点击会「穿」到猫下面的窗口
   这是故意的：窗口从头到尾不吃鼠标，所以永远不会抢焦点、不会闪。
   猫停在桌面空白处没任何影响；但如果它浮在一个文档/聊天窗口上面，
   你点它会顺带把那个窗口激活。
   （更细的做法是只让猫身区域接收鼠标、其余穿透，但那样就得动态改输入区域，
     在 Wayland 和部分驱动上容易闪，先按最稳的来。要的话我再改。）

▶ 右键猫的时候，桌面自己的右键菜单可能也会弹出来
   同上，右键落到了下面那一层。
   两个菜单打架的话，用**托盘图标**里的菜单，功能一样。

▶ Wayland 会话抓不到全局按键
   鼠标跟随仍然正常，只是猫不会跟着敲键盘。
   检查：echo $XDG_SESSION_TYPE，返回 x11 才对（UOS 默认就是 X11）。


【常见问题】

▶ 窗口背景是黑块，不是透明
   桌面合成器没开。UOS/DDE 自带，一般不会。看自检里「桌面合成器在运行」那行。
   临时绕过（画面会变成纯色背景，但能用）：
       QTWEBENGINE_CHROMIUM_FLAGS="--disable-gpu-compositing" sh run.sh

▶ 敲键盘，猫不动
   1) 确认不是 Wayland 会话：echo $XDG_SESSION_TYPE
   2) 看自检里「RECORD 扩展」那行
   3) 都不行，看自检输出里的报错

▶ 猫是白板 / 只有键盘没有猫
   显卡驱动把 WebGL 拉黑了。run.sh 已经带了 --ignore-gpu-blocklist；
   还不行就强制软件渲染（会慢一点）：
       QTWEBENGINE_CHROMIUM_FLAGS="--disable-gpu" sh run.sh

▶ 点了没反应，但鼠标跟随正常
   看菜单里「锁定位置」是不是被勾上了。

▶ ARM64 机器上有点卡
   如果自检里 OpenGL renderer 显示 "llvmpipe"，那是纯软件渲染。
   右键 → 大小 → 小（80%）会好不少；装了正常的 GPU 驱动会明显更快。


【和 Windows 版的原理差别】

   Windows：窗口能被点到，靠 WS_EX_TRANSPARENT 动态开关做穿透。

   Linux：窗口**从头到尾都不吃鼠标**（把 X11 的输入形状置空）。
          Qt 5.12+ 用 Qt.WindowTransparentForInput，Qt 5.11（UOS 20）
          没有这个属性，就自己调 libXext 的 XShapeCombineRectangles 置空。
          所以点击 100% 穿透、不抢焦点、也不会闪。
          代价是页面收不到鼠标事件，于是：
            · 光标位置 —— 每 33ms 问一次系统
            · 按键和点击 —— 用 X11 的 RECORD 扩展全局抓
            · 判定「点在猫身上」之后，再把合成的鼠标事件注入页面，
              让 cat.js 自己走摸猫 / 按键那套逻辑，模型代码一行没改


【配置存在哪】
   ~/.config/deskcat/config.json
   删掉就恢复默认。

【开机自启】
   菜单里勾「开机自动启动」，会写 ~/.config/autostart/deskcat.desktop
   不想用就把那个文件删掉。

【安装位置（deb 装的）】
   程序：/usr/share/deskcat/
   启动器：/usr/bin/deskcat
   菜单项：/usr/share/applications/deskcat.desktop
   文档：/usr/share/doc/deskcat/
