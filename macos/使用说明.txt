桌面小猫 —— macOS 版  1.0.2
（Apple Silicon / Intel 通用，macOS 11 及以上）
========================================

猫和另外两个版本是同一套（同一个 3D 模型、同一套动作逻辑），
换的只是外壳：Windows 用 Tauri，Linux 用 Qt，这里用 PyObjC + WKWebView。


【装：就三步】

   1. 双击 zip 解压（包里另外给了一份 .tar.gz，见下面「打不开」那节）
   2. 把「桌面小猫.app」拖到左边的「应用程序」文件夹
   3. 双击它
     —— 如果它被苹果拦下来（提示「无法验证开发者 / Apple 无法检查」），
        不要反复双击，直接看下面【被苹果拦下来？双击包里那个「首次打开.command」】

   第一次打开会有一个小窗口说「正在准备运行环境」，大约一分钟，需要联网。
   那个窗口自己关掉之后，猫就出现在屏幕右下角了。以后每次都是秒开。

   全程没有终端窗口，也不用敲任何命令。


【被苹果拦下来？双击包里那个「首次打开.command」】

   包里除了 app，还有一个「首次打开.command」。它专门对付苹果那道拦截，
   干两件事，别的什么都不动：

     · 清掉「从网上下载」的标记（quarantine）
     · 给这个 app 做一次本地临时签名（没有证书也能签，只在本机有效）

   怎么用（两种都行）：

     A. 直接双击「首次打开.command」
        它会弹出一个终端窗口，一行行告诉你结果，最后自己把猫启动起来。
        看到「按任意键关闭」就可以关掉那个窗口了。

     B. 如果双击 .command 也被拦（同样一句「无法验证」）：
        右键点「首次打开.command」→ 选「打开」→ 弹窗里再点「打开」。
        这一次放行之后，它会记住，以后不用再管。

   它放到哪都行：跟 app 同一个文件夹，或者 app 已经拖进「应用程序」了，
   它也会自己去 /Applications 里找。

   ★ 你也可以自己敲（最稳，等效于 A）：
        xattr -cr /Applications/桌面小猫.app
        codesign --force --deep --sign - /Applications/桌面小猫.app
        open /Applications/桌面小猫.app


【如果双击说「应用程序"桌面小猫"无法打开」】

   多半是解压时启动器丢了「可执行」权限。macOS 不会解释原因，
   只会给这一句什么也没说清的话。

   三个办法，从最省事的开始挑一个：

   ① 双击「首次打开.command」（推荐，见上一节），它会自己把权限补回来。

   ② 用同包的 .tar.gz
      那个格式自带权限位，解压出来一定是好的。双击 .tar.gz 就行，
      Finder 会自己解开成一个文件夹，里面是一样的「桌面小猫.app」。

   ③ 你已经装好了不想重下，那就修一下权限（只在这一次需要终端）
      打开「终端」，粘这一行，回车，输密码：

        chmod +x /Applications/桌面小猫.app/Contents/MacOS/deskcat

      没有报错就是好了，回去双击 app 即可。装在别处的把路径换掉。

   怎么确认是不是这个毛病（不用终端）：
      右键「桌面小猫」→「显示包内容」→ Contents → MacOS，
      里面那个 deskcat 如果双击会打开「文本编辑」，就是权限丢了。
      正常的时候它是个黑色的可执行文件，双击会在终端里刷一堆字。


【第一次打开可能被拦一下（正常）】

   先分清两种提示：
     · 「无法打开……因为 Apple 无法检查是否包含恶意软件」→ 这是拦截，看本节
     · 「应用程序"桌面小猫"无法打开」，后面没有任何解释 → 这是权限，看上一节

   双击后如果是上面第一种，按你的系统版本放行一次：

     macOS 14 及更早：右键点「桌面小猫」→ 选「打开」→ 再点一次「打开」
     macOS 15 (Sequoia) 及更新：这个右键的办法被苹果取消了，改成
        系统设置 → 隐私与安全性 → 往下拉到「安全性」
        → 会看到一行「已阻止使用"桌面小猫"」→ 点「仍要打开」→ 指纹或密码

   放行一次就够，以后永远是双击直接开。

   原因：这个程序没有花钱买 Apple 的开发者签名（一年几百块）。
   它不联网（除了第一次装运行环境）、不读你的文件、不收集任何东西。


【还有一步要你点：辅助功能权限】

   猫出来之后系统会弹一个权限窗 —— 这一步必须点，否则猫不会跟着你敲键盘：
     系统设置 → 隐私与安全性 → 辅助功能 → 把「桌面小猫」打开勾

   不给这个权限，猫也会出来、也会盯着你的鼠标看，只是不跟着敲键盘。
   勾完之后不用重启，最多等 3 秒它就自己接上了。


【它会做什么】

   · 你敲键盘：对应的爪子按到那个键上，键帽亮起，头顶弹出字符
   · 你动鼠标：一只爪子搭在小鼠标上跟着晃，眼睛盯着你的光标
   · 你点鼠标（左右键都行）：桌上那只小老鼠会被按扁、亮一下，爪子搭上去跟着按
   · 按住它的头：闭眼蹭你的手
   · 双击它：原地转一圈
   · 拖它：按住身子拖到任意位置，位置会记住
   · 你一直敲它会急：耳朵压低、瞳孔缩小、身后起红光、头顶蹦出三团红火气、耳朵冒热汽，
     忍到头会一巴掌拍在键盘上（键盘震一下），然后气消一半
   · 你不理它（哪怕一直不打字）：17 种小动作自己随机来 —— 张望、歪头、抖耳朵、舔爪、举双手伸懒腰、
     伸懒腰、打哈欠、洗脸、追尾巴、挠耳朵、蹦一下、打喷嚏、探头看你、趴一会儿、就地打个滚。
     洗脸、舔爪、挠耳朵、打滚、趴下都是先把身子矮下去再做的，不是站着比划
   · 15 分钟没人理它才睡（菜单里能改）
   · 小键盘的 0-9 也能触发（猫的键盘没有数字区，映射到上面那排数字）


【右键菜单】（在猫身上右键，或点菜单栏那个小图标）

   大小（80% / 100% / 125% / 150%）
   毛色（奶牛、橘猫、狸花、三花、白猫、蓝灰）
   多久睡着（1 / 2 / 5 / 15 分钟 / 几乎不睡，默认 15 分钟）
   转一圈 / 去睡觉
   让它表演一个（11 个动作随便挑）
   开机自动启动
   锁定位置（锁了以后鼠标彻底穿透，从菜单栏图标解锁）
   打开配置文件所在文件夹
   打开日志文件
   退出小猫
   软件均是免费开源，切勿商用买卖（这行是声明，灰的，点不动）


【出问题了怎么办】

   不用开终端。在菜单里点「打开日志文件」，访达会选中
   ~/Library/Logs/DesktopCat.log —— 把那一个文件留着，基本就能定位。

   顺带看一眼：
     · 猫是白板 / 只有键盘没有猫 → 显卡或 WebGL 的问题，日志里会有记录
     · 敲键盘它不理 → 还是辅助功能权限没打开（系统设置里那项要打勾）
     · 说「准备失败」 → 多半是连不上网，装 PyObjC 需要联网（约 20MB）
     · 辅助功能的勾每次开机都自己掉 → 没签名的小程序偶尔会这样。
       把「桌面小猫」从辅助功能列表里用「−」删掉，再重新添加一次就好。


【常见问题】

▶ 提示「这台 Mac 还没有 Python 运行环境」
   点弹窗里的「去安装」，会打开 Apple 官方的命令行工具安装窗口，装完再双击一次。
   macOS 一般自带，只有很干净的机器才会遇到。

▶ 提示「无法打开，因为无法验证开发者」
   14 及更早：右键 →「打开」→ 再点「打开」。
   15 及更新：系统设置 → 隐私与安全性 → 安全性那一栏点「仍要打开」。
   只需要放行一次。

▶ 装完想换电脑 / 发给别人
   整个「桌面小猫.app」拷过去就行，对方第一次打开会自动准备环境。
   配置文件在对方自己的 ~/Library 里，不会跟着走。

▶ 会不会抢焦点 / 挡住我点东西？
   不会。窗口设了「不接受鼠标事件」，鼠标 100% 穿过去，永远不会成为活动窗口。
   代价是你点在猫身上时，点击会落到猫下面那个窗口 —— 和另外两版一样，
   这是有意的取舍（换来永不闪烁、永不抢焦点）。

▶ 睡着的猫不动 / 想叫醒它
   晃晃鼠标再回来，或者菜单 →「转一圈」。菜单里也能改「多久睡着」。


【卸载】

   把「桌面小猫.app」从「应用程序」里拖到废纸篓，然后删掉这两个目录：
     ~/Library/Application Support/DeskCat      （运行环境 + 配置，约 100MB）
     ~/Library/Logs/DesktopCat.log              （日志）
   如果开过开机自启，再删 ~/Library/LaunchAgents/com.deskcat.pet.plist


【里面有什么 / 为什么第一次慢】

   桌面小猫.app 里只有四样东西：
     · 一个启动器（系统执行用的，你看不到它）
     · 图标
     · 网页和 3D 模型（和 Windows / Linux 版同一个文件）
     · 一个压缩过的脚本块（不是可读的源码；第一次启动时才在这台机器上
       编译成字节码，所以换了 Python 版本也不会坏）

   第一次启动为什么要等：要下载 PyObjC（Python 调系统窗口和键盘的桥，约 20MB）。
   装完之后它存在你的 ~/Library 里，以后就不再联网了。


【为什么不是「拖进去就能跑」的单个二进制】

   老实说：macOS 的原生程序（Swift / Tauri / Electron）必须在 Mac 上用 Xcode 编译，
   而这次是在 Windows 上做的，编不了。
   想做到零依赖，就得把一整个 Python 运行时（约 50MB）打进包里，
   但那个运行时要从 GitHub 下载，这边下不动。
   所以现在这版是「自带安装逻辑的 .app」：双击就能用，你看到的只有系统弹窗，
   没有终端、没有命令、也没有可读的源码。
