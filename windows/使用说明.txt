桌面小猫（轻量版） 使用说明
========================================

单个 exe，3.5 MB，不用安装、不用解压，双击就跑。

本软件免费开源，请勿商用买卖。


【怎么用】
1. 双击「桌面小猫.exe」，猫就出现在屏幕右下角。
2. 拖它：按住身子拖到任意位置，位置会记住，下次还在那。
3. 找不到它了 / 想调设置：看屏幕右下角托盘里的小猫图标，点一下出菜单。
4. 想关掉：右键小猫 → 「退出小猫」，或托盘图标 → 「退出小猫」。
5. 想让它开机就出现：右键小猫 → 勾选「开机自动启动」。


【它会做什么】
· 你敲键盘：对应的爪子按到那个键上，键帽亮起，头顶弹出字符（小键盘也支持）
· 你动鼠标：一只爪子搭在小鼠标上跟着晃，眼睛盯着你的光标
· 你点鼠标（左键/右键都算，点桌面哪儿都行）：桌上那只小老鼠会被按扁、亮一下，
  爪子搭上去跟着按；右键它会往另一边歪，跟真的被你按到一样
· 按住它的头：闭眼蹭你的手，头顶飘爱心
· 双击它：原地转一圈
· 拖它：拖到桌面任意位置
· 你不理它（哪怕一直不打字）：17 种小动作自己随机来 —— 左右张望、歪头、
  抖耳朵、舔爪子、伸懒腰（两只前爪举起来，身子往上拔）、打哈欠、洗脸、追自己的尾巴、挠耳朵、蹦一下、
  打喷嚏、探头看你、趴一会儿、就地打个滚……
  其中洗脸、舔爪、挠耳朵、打滚、趴下是先把身子矮下去再做的，不是站着比划。
· 15 分钟没人理它，才趴下来睡着冒 z Z z（可以右键改这个时间）


【你一直敲，它会急】
· 只有「真的在猛敲」才算：每秒 7 下以内（正常打字、写代码、聊天）完全不涨火气
· 每秒 7 下以上才开始急，越快涨得越猛：尾巴越甩越快，耳朵往后压，瞳孔缩小
· 再敲：整只猫泛红——身后起一团红光，头顶蹦出三团红色火气，头开始发抖
· 再敲：耳朵冒热汽
· 忍到头：一巴掌拍在键盘上（键盘震一下、红光闪一下），然后气消一半
· 手一慢就自己消，停手三秒基本就退干净了


【右键菜单】
大小（80% / 100% / 125% / 150%）
毛色（奶牛、橘猫、狸花、三花、白猫、蓝灰）
多久睡着（1 分钟 / 2 分钟 / 5 分钟 / 15 分钟 / 几乎不睡，默认 15 分钟）
转一圈
去睡觉
让它表演一个 ▸（打个滚 / 伸懒腰 / 洗脸洗手 / 追自己的尾巴 /
                抬爪打招呼 / 探头看看 / 挠耳朵 / 原地蹦一下 /
                打喷嚏 / 打哈欠 / 趴一会儿）

锁定位置（锁定后鼠标彻底穿透，点不到它，只能从托盘菜单解锁）

【几个说明】
· 点它、摸它都不会抢走你正在打字的窗口焦点，光标也不会跳。
· 猫身以外的地方鼠标完全穿透，不挡你点桌面。
· 让它睡觉后，30 秒内你随便晃鼠标不会吵醒它；敲键盘或者大幅移动鼠标才会醒。
· 点「让它表演一个」里任意动作，会立刻做给你看；这时你一动键盘，它就让位给打字。
· 设置保存在 %APPDATA%\com.deskcat.app\config.json，删掉这个文件夹就恢复默认。
· 只支持 64 位 Windows 10 / 11。


【系统要求 / 打不开怎么办】
这个版本用的是系统自带的 WebView2 内核（Win11 和大部分 Win10 都已预装），
所以体积只有 3.5 MB，而不用像 Electron 版那样塞一整个 Chromium 进去。

万一双击后没反应、或者窗口一片空白：
装一下微软官方的「Microsoft Edge WebView2 Runtime」（免费，几 MB），再启动即可。


【第一次运行会被 Windows / 杀毒软件拦，这是正常的】
· 弹出「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」。
  原因：这个 exe 没有购买代码签名证书（要几千块一年），不是病毒。
· 杀毒软件可能提示「键盘记录」类风险。这是因为它要读取你的按键，才能让猫跟着敲键盘。
  所有按键只在你自己电脑的内存里处理，不联网、不上传、不留任何记录。
  遇到拦截选「允许」/「信任」，或把 exe 加入白名单。


【如果敲键盘它不动】
全局键盘钩子被安全软件拦了。把 exe 加入白名单后重启小猫即可；
鼠标跟随不依赖钩子，一般仍然正常。
